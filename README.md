## 📚 Overview

**AI Study Planner** explores how prompt engineering can help students request a study plan based on their mood, available time, and study goals. The repository currently documents a Google AI Studio prompt-based concept.

## ✨ Intended Capabilities

- Suggest a study schedule based on the user's stated time.
- Adapt the tone or plan to the user's mood.
- Offer practical motivation and productivity suggestions.
- Break study goals into manageable steps.

These are described as prompt-based behaviours, not verified features of a standalone deployed app.

## 🧠 Approach

- **Google AI Studio** for AI prototyping.
- **Prompt engineering** to guide the response format and planning behaviour.
- **Generative AI** to produce conversational suggestions.

## 🔄 Conceptual Workflow

1. Share study goals, available time, and preferred study style.
2. Use a prompt to request a structured plan.
3. Review the suggested time blocks and tasks.
4. Adjust the plan to match deadlines, energy, and actual workload.

## ⚠️ Current Scope

The repository currently contains the README only; no application source, dependency file, or setup command is included yet. Treat this as a project concept until the runnable implementation is added.

## 🔮 Future Improvements

- Build a Streamlit or mobile interface.
- Add editable tasks and break reminders.
- Save plans locally.
- Test prompts against different subjects and schedules.
